# To-Do List App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Display tasks dynamically
- Delete tasks
- Mark tasks as completed
- Interactive user interface
- Task management

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `todo.html` – Application structure
- `todo.css` – Application styling
- `todo.js` – Task management functionality

## Purpose
This project demonstrates my understanding of JavaScript DOM manipulation, event handling, and dynamic content updates.
